# Icon assets — La Capitaine

The SVGs in `mimetypes/` and `places/` are from the
[La Capitaine](https://github.com/keeferrourke/la-capitaine-icon-theme)
icon theme by Keefer Rourke, licensed **CC-BY-SA 4.0**.

- mimetypes: application-audio, application-pdf, application-image-png,
  application-image-tiff, application-archive, application-json,
  application-video, application-text
- places: folder, folder-music, folder-pictures, folder-documents

Used by the Drive screen (per-file mimetype icons + dominant-kind folder icons).
Attribution is required if this ships.
